# OctoFlow - Automated Medicine Dispenser

## Overview
OctoFlow is an ESP32-based automated medicine dispenser prototype under development.

## Current Hardware
- ESP32 Development Board
- 28BYJ-48 Stepper Motor
- ULN2003 Driver
- LSD-0530B Push-Pull Solenoid
- 5V Relay Module
- LCD Display
- LDR + White LED
- Custom KiCad PCB (in progress)
- 3D Printed Enclosure

## Software
- Arduino IDE
- KiCad
- Blender
- Tinkercad
- Firebase (planned)

See folders for hardware, firmware, mechanical, docs and images.

Prototype under active development.
